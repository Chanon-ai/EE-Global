# Global Practice

เว็บฝึกข้อสอบภาษาอังกฤษ 4 ตัวเลือก พร้อมเฉลยและคำอธิบายภาษาไทย สุ่ม 50 ข้อไม่ซ้ำในรอบ ทำซ้ำได้ บันทึกความคืบหน้าและคะแนนไว้ในเบราว์เซอร์ มีหน้าทบทวนข้อที่ผิด รองรับมือถือและแป้นพิมพ์ 1–4 / ลูกศร

## เปิดใช้งาน

เปิด `dist/index.html` ได้โดยตรง หรือใช้ Node.js:

```sh
npm start
```

เข้า http://127.0.0.1:4173

## เนื้อหา

คลังคำถามใน `questions.txt` เรียบเรียงจาก `(Update) สิ่งที่ควรรู้ก่อนสอบ Global 2026.pdf` และ `Global EE Exam🏠🐶🌼.pdf` ใน `../Data/Global` โดยเลือกข้อความที่ชัดเจน ไม่ใช้ข้อที่ต้องอาศัยภาพที่ขาดหายหรือมีหลายคำตอบ ข้อเกี่ยวกับเหตุการณ์เก่าระบุปีในคำถาม ไม่ใช้ข้อที่อ้างจำนวนสมาชิกหรือผู้นำปัจจุบัน ภาพ PNG ใน Data ยังไม่ได้ใช้ในคลังรุ่นนี้

แต่ละบรรทัด: หมวด | คำถาม | คำตอบที่ถูก | ตัวลวง 3 ตัว | คำอธิบายไทย ตัวเลือกถูกจะถูกสุ่มตำแหน่งใหม่ในแต่ละรอบ

หลังแก้เนื้อหา รัน `npm run build` เพื่อสร้าง questions.js และคัดลอกเอกสารอ้างอิง จากนั้น `npm test` เพื่อตรวจจำนวนตัวเลือก การสุ่ม การจับคู่คำตอบ การล็อกคำตอบ และคะแนน

ข้อมูลการฝึกอยู่ใน localStorage ของแต่ละเบราว์เซอร์ ไม่ส่งคะแนนไปเซิร์ฟเวอร์ รอบใหม่อาจมีคำถามจากรอบเก่า เพราะสุ่มจากคลังเดียวกัน

## คำถามรูปภาพ

เพิ่มคำถามระบุบุคคล 13 ข้อใน `image-questions.json` ใช้ภาพและชื่อกำกับจาก PDF ฉบับ Update หน้า 32–35 ภาพสกัดจากต้นฉบับไว้ใน `dist/images` และใช้ชื่อไฟล์กลางที่ไม่บอกคำตอบ รูปภาพขยายได้ทั้งหน้าทำข้อสอบและหน้าทบทวน

แต่ละรอบใหม่มีข้อทั่วไป 45 ข้อและข้อรูปภาพ 5 ข้อ สุ่มทั้งลำดับคำถามและตัวเลือก รอบที่บันทึกไว้ก่อนการอัปเดตยังสามารถทำต่อได้ตามเดิม
